# Nihal Hasain C — Portfolio (V2 refined)

This is the V2 portfolio with the original intro/hero retained. The existing dark, cyan, and blue palette and section layouts are kept. The content below the intro uses a clean system font, subtle hover feedback, and scroll reveal effects that fade in as content enters view and fade out as it leaves. With JavaScript disabled, all sections remain visible.

## Preview and deployment

1. Keep all files in this folder together.
2. Open `index.html` in a browser to preview it.
3. Upload all files to the same folder on your host. Do not upload only `index.html`.

## Updating content

- **About and education:** Edit the relevant text and education entries in the `#about` section of `index.html`.
- **Skills and tools:** Edit the cards and tool groups in `#skills`. To add a skill or tool, copy a `<span>` from the matching group and change its text. Keep categories factual and remove items you no longer use.
- **Certifications:** Copy a `.cert-card-new` inside `#certifications`, then change the title and description. Add a verification link only if you have a real URL.
- **Experience:** Copy an `.experience-item` inside `#experience`; update employer, role, dates, and responsibilities.
- **Labs:** Copy a `.lab-card` inside `#labs` and update the description, tools, and workflow. Use only authorized lab work in examples.
- **Projects:** Copy a `.project-card-new` inside `#projects`, then change its title, summary, technology labels, and live/source link.
- **Contact:** Update the email, phone, LinkedIn URL, and location in `#contact`.
- **Resume:** Replace `nihal-resume.pdf` with the new file using the same filename, or update the resume link.
- **Profile photo:** Replace `nihal.jpg` with the new image using the same filename, or update its references.

## Add project cover images

Create an `images` folder beside `index.html`. Put the screenshot in that folder. In the relevant project card, add `has-cover` to the preview container and add an image as its first child:

```html
<div class="project-art art-phish has-cover">
  <img class="project-cover" src="images/phishing-detector.jpg"
       alt="Screenshot of the phishing detection application" loading="lazy">
  <!-- Existing preview elements may remain; they are hidden while has-cover is present. -->
</div>
```

Use a clear screenshot, ideally around 16:9. Keep the `alt` text brief and accurate. Remove `has-cover` and the image to return to the built-in preview.

## Add an image to another section

The `content-cover` class can be used inside About, Education, Experience, Skills, or Lab cards:

```html
<img class="content-cover" src="images/lab-screenshot.jpg"
     alt="Wireshark capture showing DNS traffic" loading="lazy">
```

Place the image inside the card where it should appear. Create the `images` folder if needed and keep its relative path correct. The same class maintains the site's existing border and sizing.

## Styling and effects

- `portfolio-refinements.css` holds shared refinements, hover effects, reveal transitions, and optional image-cover styles.
- The core palette is in the `<style>` block in `index.html`: `--bg-dark`, `--bg-card`, `--primary`, and `--secondary`.
- The hero uses the original styling; the system font and new reveal effects apply only below it.
- Respect reduced-motion settings. Main section content is in the HTML, not generated by JavaScript.

## SEO and content

The page has a title, description, canonical URL, social-sharing metadata, semantic headings, and Person structured data. Keep them accurate if the domain or portfolio focus changes. Avoid unsupported claims, made-up statistics, or keyword stuffing.
